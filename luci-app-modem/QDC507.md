# DJI / Baiwang QDC507

本适配针对 QDC507 的 LTE Quectel AT 指令集。已使用 iStoreOS 25.12.5 x86_64、QDC507GLEFM21、USB `2c7c:0125` 和 ECM 模式验证；其他固件、架构及 USB 模式尚未完成实机验收。

## 拨号与模组信息

- 识别包含 `qdc507` 的型号字符串，读取信号、温度、SIM 信息及本机号码。
- 使用 `AT+CGACT` 激活或停用 PDP。空 APN 保留现有运营商配置。
- 首次拨号创建 `wwan_5g_<编号>` DHCP 接口；发现同一设备已有 DHCP 接口时复用。接口名称记录在模组的 `managed_interface` 中，避免重复创建 DHCP 客户端。
- 新建接口默认 metric 为 10；复用接口保留其现有配置。本适配当前只创建 IPv4 DHCP 接口。
- AT 查询使用按串口命名的 `flock` 锁；两个 LuCI 包均声明相应依赖。

接口 metric 可能影响默认出口，部署前请检查现有路由和防火墙。不要同时为同一网络设备维护多个 DHCP 接口。

## 网络制式与 LTE 频段

支持 GSM / WCDMA / LTE 组合设置及 LTE 频段限制。频段掩码按十六进制字符串处理，避免 B66/B71 超过 Lua 数值的精确整数范围；写入 LTE 掩码时保留原 2G/3G 参数。

设置后读取参数确认；参数实际改变时执行 `AT+CFUN=0`、`AT+CFUN=1` 重新启用无线功能，会短暂中断连接。参数读回成功不代表已重新注册运营商网络。锁频段不是锁定小区或 EARFCN；2G/3G 能否注册取决于运营商覆盖。

## 短信

短信入口统一到“网络 → 移动通信模组 → 短信”，收件箱、发送、USSD、AT 和设置页提供直接导航。单独安装短信插件时仍会创建其所需菜单。

自动端口探测优先复用模组插件已识别的 QDC507 AT 端口，不探测该模组的 DIAG/GNSS 端口。短信配置仍然只管理一个 AT 端口，并非多模组短信控制台；插拔后请按实际设备识别结果检查端口。

`sms-tool` 的补丁修复带符号 `char` 导致的 JSON 中文及特殊字符乱码。长短信按发件人、拼接参考编号和总段数分组，再按段序号排列；缺段会提示，同组出现重复段号时保留原分段。新安装默认开启长短信合并。

独立后台服务每 10 秒将短信原始 PDU 与解码内容持久保存到路由器，完成文件和目录同步、读回、SIM 身份与逐槽核验后释放模组空间。浏览器每 5 秒读取本地记录，关闭页面仍会收件。发送、USSD、AT、LED 查询和后台收件共享串口锁，发送正文中的单引号等内容按独立参数处理。

本地归档权限、升级步骤、删除范围和非 QDC507 设备的兼容边界见 [短信插件说明](../luci-app-sms-tool/README.md)。本 PR 保留 GPL、Apache、BSD 和 HTML Tidy 原文与作者声明，并在安装目录携带修改说明。

## 回归测试

在仓库根目录执行，无需连接模组：

```sh
node luci-app-modem/tests/qdc507_view_test.js
python3 luci-app-modem/tests/cnum_test.py
node luci-app-sms-tool/tests/inbox_test.js
node luci-app-sms-tool/tests/inbox_view_test.js
lua luci-app-modem/tests/qdc507_band_test.lua
lua luci-app-sms-tool/tests/menu_test.lua
```

控制测试需要 OpenWrt 的 `luci.jsonc`、`luci.util`，以及 `/usr/share/modem/` 下对应的频段模块和模组定义。它替换 AT 执行器，不发送真实指令：

```sh
lua luci-app-modem/tests/qdc507_control_test.lua \
    luci-app-modem/root/usr/share/modem/baiwang_control.lua
```

短信归档、保存失败和输入转义的 Lua 回归测试需要 OpenWrt Lua 5.1 与 LuCI 库，命令见 [短信插件说明](../luci-app-sms-tool/README.md)。这些夹具不访问物理串口。

在 `sms-tool` 固定上游版本依次应用包内 `0001` 到 `0004` 四个补丁后，使用已打补丁的 C 源码验证 17 个码点在 signed / unsigned char 下的 JSON 输出：

```sh
python3 sms-tool/tests/json_encoding_test.py /path/to/patched/sms_main.c
```

`sms-tool/tests/pdu_replay.c` 通过自行创建的伪终端回放模拟 UCS2 短信与错误原始 PDU；不要将夹具替换为真实串口。
